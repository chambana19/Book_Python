ARC 500 · SPYDER INSTALLATION AND COURSE ENVIRONMENT GUIDE
Fall 2026 · reviewed 2026-08-20

PURPOSE

Use one stable Python environment for the semester. Spyder is the IDE: it
provides the Editor, IPython Console, Variable Explorer, Files pane, and other
tools. The Python interpreter and installed libraries form the environment
that actually runs your .py files.

RECOMMENDED COURSE PATH: MINIFORGE + THE ARC500 ENVIRONMENT

This is the supported course path because later work uses NumPy, pandas,
Matplotlib, SciPy, scikit-learn, and GeoPandas. Spyder's current documentation
recommends Miniforge or another Conda-based distribution when students need
specialized packages beyond the standalone install.

1. Download and install Miniforge from its official project page:
   https://github.com/conda-forge/miniforge
2. Open Miniforge Prompt on Windows, or a terminal on macOS/Linux.
3. Change to the folder containing ARC500_environment.yml.
4. Create the tested course environment:

   conda env create -f ARC500_environment.yml

5. Activate it:

   conda activate arc500-f26

6. Run the course preflight before opening Spyder:

   python ARC500_environment_preflight.py

7. Install and launch the Spyder application using its official standalone
   installer. In Spyder 6, choose Consoles > New console in environment and
   select arc500-f26. If it is not listed, use Tools > Preferences > Python
   interpreter and choose the Python executable printed by this command:

   conda run -n arc500-f26 python -c "import sys; print(sys.executable)"

8. Restart the Spyder kernel, open ARC500_environment_preflight.py, and run it
   once more inside Spyder. The executable must point to arc500-f26.

IMPORTANT INSTALLATION RULE

Do not install course packages into Spyder's standalone internal environment
from the IPython Console. Do not mix pip packages into arc500-f26 unless the
instructor explicitly supplies the command. Update or rebuild from the shared
YAML so that every student's environment remains comparable.

ALTERNATIVE: STANDALONE SPYDER FOR WEEKS 1-6 ONLY

The standalone installer includes common scientific libraries and may pass
the early NumPy/pandas/Matplotlib work. It is not the supported route for the
full semester unless it is connected to arc500-f26. GeoPandas depends on a
compiled geospatial stack; GeoPandas recommends Conda/conda-forge as the
easiest installation path.

VERIFY INSIDE SPYDER

Open ARC500_environment_preflight.py, save it in the course folder, and run
the file. A passing report checks:

- the active Python executable and working folder;
- required imports and their versions;
- a small NumPy/pandas calculation;
- a Matplotlib figure created without opening a GUI;
- a GeoPandas CRS transformation;
- a SciPy linear-program solve; and
- a scikit-learn fit/predict cycle.

The final line must read:

   ARC500 PREFLIGHT: PASS

SPYDER WORKFLOW CHECKLIST

- Save the .py file before running it.
- Set the working directory to the current module folder.
- Use # %% to create meaningful code checkpoints.
- Press Ctrl+Enter to run the current cell.
- Inspect output in the IPython Console.
- Inspect names, values, and types in Variable Explorer.
- Restart the kernel and run from the top before submission.
- Record any generative-AI assistance and how each retained suggestion was
  tested.

TROUBLESHOOTING ORDER

1. Read the final line of the error message.
2. Run ARC500_environment_preflight.py and save its complete output.
3. Print sys.executable and Path.cwd().
4. Confirm that the active console uses arc500-f26.
5. Test the failing import in a new file with no other code.
6. If the environment is damaged, rebuild it from ARC500_environment.yml
   instead of trying several unrelated installation commands.
7. Bring the exact error, preflight output, OS, and attempted steps to class or
   office hours.
