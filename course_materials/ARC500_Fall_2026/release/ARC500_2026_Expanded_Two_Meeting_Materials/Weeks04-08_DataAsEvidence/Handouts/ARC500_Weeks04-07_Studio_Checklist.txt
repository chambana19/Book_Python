HOW TO READ A STOP
[ ] EXPECTED TODO STOP = the scaffold protected you from an unfinished result.
    Complete the named cell; do not delete the gate or replace evidence with True.
[ ] * CHECK FAILURE / DATA ERROR = code ran, but a known fact, file, schema, or unit
    is wrong. Read the message, inspect inputs, and repair the cause.
[ ] Before submission: restart the kernel and Run File from the top. Zero errors,
    no TODO output, and a visible check must precede every export.

EVERY STUDIO — THE FIVE-VERB ROUTE

LOAD
[ ] File paths use pathlib; input data is never overwritten.
[ ] Working folder and expected input filenames are visible in cell [0]/[1].

CHECK
[ ] Predict row/column counts before loading; compare after loading.
[ ] Inspect columns, dtypes, missing values, duplicates, and plausible ranges.
[ ] Name the unit, meaning of one row, provenance, and at least one limitation.

TRANSFORM
[ ] Preserve source columns; give derived columns concept-and-unit names.
[ ] Every drop, correction, or retained gap has a written reason.
[ ] Missingness and outlier status remain separate Boolean flags.

VERIFY
[ ] Run the required transfer cell on a different row/column than the live example.
[ ] Assertions check values, schema/shape, boundaries, and row accounting.
[ ] A flag prompts KEEP / INVESTIGATE / EXCLUDE; it never silently deletes a row.

EXPORT
[ ] Export only after checks pass; use index=False for CSV.
[ ] Reopen each CSV; compare shape, column order, and finite numeric values.
[ ] Inspect every PNG/GIF at full size: data marks, title, units, legend/source, no clipping.
