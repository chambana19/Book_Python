\noindent{\Large\bfseries INTRODUCTION TO PROGRAMMING WITH PYTHON}\\[3mm]
\noindent{\small PROGRAMMING FOUNDATIONS, ALGORITHMS, DATA ANALYSIS, \\
VISUALIZATION, GEOSPATIAL COMPUTING, OPTIMIZATION, AND MACHINE LEARNING}

\vspace{3mm}
\noindent{\color{BookBlue}\rule{0.92\textwidth}{1.75pt}}\\[8mm]

\begin{minipage}{0.86\textwidth}
This independent-study textbook develops computational thinking through
runnable Python programs. Each chapter connects syntax to an algorithm,
explains why the program works, displays meaningful results, and ends with a
graduated practice ladder and solutions.

\vspace{5mm}
\textbf{Students learn to:}
\begin{itemize}
    \item design, trace, test, and improve reliable programs;
    \item choose data structures and algorithms with attention to efficiency;
    \item analyze numerical, tabular, visual, and geospatial data;
    \item formulate and verify numerical optimization models; and
    \item build and evaluate introductory machine-learning workflows without
          confusing prediction with explanation.
\end{itemize}
