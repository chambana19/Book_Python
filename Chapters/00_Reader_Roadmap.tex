\h*{Reader Roadmap}
\label{reader:roadmap}

This book is organized as a progression from individual instructions to
complete analytical applications. The links below provide seven useful entry
routes. If you are new to programming, begin with the first route and continue
in order.

\begin{tcolorbox}[title=Choose a learning route,colframe=orange,colback=white,arc=2mm]
\begin{itemize}
    \item \textbf{Learn Python from the beginning:}
          \booklink{ch:01}{Chapter 1} through \booklink{ch:05}{Chapter 5}.
    \item \textbf{Build reliable, reusable scripts:}
          \booklink{ch:06}{Chapter 6} through \booklink{ch:10}{Chapter 10}.
    \item \textbf{Analyze and communicate data:}
          \booklink{ch:11}{NumPy}, \booklink{ch:12}{pandas}, and
          \booklink{ch:13}{Matplotlib}.
    \item \textbf{Handle data that is not already a table:}
          \booklink{ch:14}{structured, semi-structured, and unstructured data}.
    \item \textbf{Work with geographic data:}
          \booklink{ch:15}{GeoPandas foundations} followed by
          \booklink{ch:16}{geodatasets and applied mapping}.
    \item \textbf{Study computational methods:}
          \booklink{ch:17}{algorithms and efficiency},
          \booklink{ch:18}{numerical optimization}, and
          \booklink{ch:19}{machine-learning foundations}.
    \item \textbf{Go deeper into search and modeling:}
          \booklink{ch:20}{gradient-based and metaheuristic optimization},
          \booklink{ch:21}{classification and model selection}, and
          \booklink{ch:22}{neural networks}.
\end{itemize}
\end{tcolorbox}

\hh*{Key destinations}

\begin{itemize}
    \item See the \booklink{sec:c13-showcase}{visualization showcase} for a
          compact gallery of analytical plot types.
    \item Follow the \booklink{sec:c13-dashboard}{building-performance
          dashboard} for a longer, practical Matplotlib script.
    \item Trace three kinds of source into one feature table in
          \booklink{ch:14}{the structured and unstructured data chapter}.
    \item Use the \booklink{sec:c15-application}{site-access application} to
          connect coordinates, projection, distance, and buffers.
    \item Complete the \booklink{sec:c16-application}{Chicago mapping
          application} to load an educational dataset, align coordinate
          systems, join layers, summarize results, and export a figure.
    \item Compare searches in the
          \booklink{sec:c17-application}{algorithm application}, verify a
          \booklink{sec:c18-application}{bounded optimization model}, and
          evaluate a protected test set in the
          \booklink{sec:c19-application}{machine-learning application}.
    \item Benchmark gradient descent against three metaheuristics in the
          \booklink{sec:c20-application}{facade design application}, select
          a model without spending the test set in the
          \booklink{sec:c21-application}{comfort-complaint triage}, and build a
          network from arrays in the
          \booklink{sec:c22-application}{neural-network application}.
\end{itemize}

Every chapter follows the same rhythm: learning outcomes, concepts, syntax
analysis, runnable snippets, visual results where appropriate, guided practice,
solutions, and a checkpoint. Blue text in the PDF is clickable. The footer on
content pages returns to the contents or this roadmap.
